# PMSI — Polymarket Sentiment Indicators

## Architecture

```
pipeline/          Python data pipeline (runs daily via cron)
  config.py        Sector definitions, search terms, keyword rules, asset patterns
  discovery.py     Polymarket Gamma API market discovery (bulk + search + tags)
  classifier.py    LLM classification of markets into categories + polarity
  snapshot.py      Orchestrator: discover → classify → score → save snapshots
  prices.py        Reference price feeds (CoinGecko, Yahoo Finance, FRED, Alternative.me)
  db.py            Dual-backend database (Postgres prod / SQLite dev)
  export.py        Export DB → static JSON for frontend (latest.json, sandbox.json per sector)

public/            Static frontend (served by Vercel)
  index.html       Single-page app shell
  js/sectors.js    Sector registry, reference assets, chart colors
  js/app.js        Data loading, sector cache, routing
  js/sandbox.js    Builder page, indicator CRUD, backtest, market picker
  js/auth.js       Wallet + email auth
  js/api-panel.js  API key management page
  data/            Static JSON data files (generated by export.py)

api/               Vercel serverless functions
  _lib/compute.js  Server-side indicator computation from market_snapshots
  _lib/db.js       Postgres connection for serverless
  indicators/      Indicator CRUD API
  v1/, v2/         Public API endpoints
```

## Sectors

Four sectors, each with its own categories, reference data, and search terms:

| Sector   | Categories                                               | Primary ref     |
|----------|----------------------------------------------------------|-----------------|
| crypto   | price_targets, regulatory, adoption, events              | BTC, F&G        |
| stocks   | price_targets, earnings, corporate                       | S&P 500, VIX    |
| economy  | monetary_policy, inflation, growth, employment           | 10Y yield, Fed  |
| politics | favors_incumbent, favors_challenger, legislative, geopolitical | (none)     |

## Reference Price Feeds

16 feeds across 4 groups, all stored in `reference_prices` table:
- **Crypto:** btc_price, eth_price, sol_price, fear_greed
- **Equities:** spx_price, ndx_price, dji_price, rut_price, vix_price
- **Rates/Macro:** us10y_yield, us2y_yield, dxy_price, fed_rate, unemployment
- **Commodities:** gold_price, oil_price (always included cross-sector)

## Builder Features

- Per-market selection with weight sliders (0-200%)
- Per-market polarity flip (invert signal for bearish markets)
- Market config format: `{ mid: { w: number, flip: boolean } }`
- "Test Against" dropdown with grouped reference assets
- Backtest with 3 strategies: momentum, contrarian, long_only
- Fear & Greed index blending
- Cross-sector market mixing supported

## Key Commands

```bash
# Pipeline
cd pipeline
python3 snapshot.py --sector crypto -v      # Run full pipeline for a sector
python3 prices.py                           # Fetch all reference prices
python3 export.py --sector crypto --out ../public/data -v

# Dev server
cd .. && npx vercel dev                     # Runs on localhost:3000

# Deploy
vercel --prod
```

## Database

- **Postgres** (production): connection via `DATABASE_URL` env var
- **SQLite** (dev fallback): `pipeline/sentiment.db`
- Key tables: `market_snapshots`, `reference_prices`, `sector_daily`
- Migrations run automatically on connect (ALTER TABLE ADD COLUMN IF NOT EXISTS)
- `_REF_COLS` in db.py lists all 16 reference price columns
